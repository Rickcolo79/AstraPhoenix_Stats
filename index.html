Esporta e importa dati

Usa il backup JSON per conservare l'intero archivio con roster, partite ed eventi. I CSV consentono di scambiare i dati e importarli in fogli di calcolo.

I backup UISP e FIP sono archivi completi separati: includono partite, giocatori ed eventi della sola competizione scelta. Il backup generale contiene entrambe.

Importa backup completo

L'importazione di un backup sostituisce l'archivio corrente in questo browser. Fai prima un backup dei dati presenti.

Importa CSV eventi

Il CSV eventi esportato da questa app può essere reimportato. Le righe con ID evento già presenti vengono ignorate.

Pubblicazione statistiche (file per il sito)

Scarica un file JSON pubblico con le sole informazioni sportive e un file HTML di consultazione. Per aggiornare il sito pubblico, carica il file generato nel tuo repository/hosting statico seguendo la guida inclusa nel pacchetto.

Guida rapida

  1. Crea una partita nella sezione Partite, poi apri Compilazione.
  2. Aggiungi i giocatori di entrambe le squadre. Seleziona i cinque titolari Astra Phoenix e premi «Imposta quintetto iniziale». Ripeti la selezione/cambio di stato per gli avversari: la gestione è separata.
  3. Durante la compilazione: tocca direttamente il giocatore, poi l’azione. La squadra viene selezionata automaticamente. Per un tiro da 2 o 3 scegli la zona; per i liberi no.
  4. Per una sostituzione, seleziona chi esce e chi entra. Il cambio registra anche il tempo corrente come riferimento.
  5. Esporta spesso il backup JSON. Il CSV è utile per trasferimento e analisi, ma il JSON conserva l'intero archivio per ripristinarlo.
  6. Per pubblicare le statistiche, genera i dati pubblici JSON e aggiorna il sito statico. Il link pubblico rimane lo stesso se sostituisci i file sullo stesso sito. I backup completi UISP/FIP sono invece file privati di archivio e non vanno caricati sul sito pubblico.
Limiti da conoscere: questa è un'app locale, non un sistema multiutente sincronizzato. I dati rimangono nel browser e nel dispositivo finché non esporti il backup. Il timer del browser non sostituisce il cronometro ufficiale. Plus/minus e alcune metriche avanzate richiedono una registrazione coerente di ogni evento di punteggio, quintetto e minuti: controlla i risultati prima di considerarli ufficiali.

Per il sito pubblico, non pubblicare informazioni personali non necessarie. Pubblica solo i dati sportivi che vuoi rendere accessibili a tutti.
